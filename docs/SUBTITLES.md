# 房间字幕库与同步

主持人“Add room subtitles”上传自己有权使用的 SRT/VTT。每个房间最多 12 轨、
单轨 UTF-8 内容最多约 768 KiB；过大的字幕应清理格式/无用内容，不要上传可执行脚本。
字幕内容存于房间 Durable Object 并可供授权房间成员获取；不是只保留在上传者内存。

每个人独立选择语言、大小及 ±1 秒偏移，不会改变其他人的语言。
示例见 examples/subtitles，只有项目自写的短句，不能作为电影字幕。
使用实际影片字幕时核对集数、片长、帧率版/剪辑版、片头和广告差异。

## 自动同步适用范围

从房间打开的本地电影播放器，通过 Share local player 共享时，字幕以 video.currentTime
为准。暂停、播放、跳转、倍速、缓冲会更新时钟；外置 M4A 不是新的字幕零点。
可以先把电影拖到中间，绑定共享源时读取最新位置。无法识别 Capture Handle 时会提示
主持人确认是否分享本站本地播放器，不要对其他网站点“确定”。

更新版本后双方刷新、关闭旧源页再重新打开，避免旧代码与新房间混用。
只有 Share local player 才能明确约束 Chrome 标签页来源，窗口/全屏共享不等价。

外部腾讯视频等站点不向本站公开播放时间，当前仍需手动暂停字幕和调偏移；
本站没有侵入其他网站、跨域读取其播放器、安装扩展或自动生成时间戳的能力。

## 内嵌、硬字幕和翻译

浏览器暴露的可关闭文本 TextTrack 会禁用。PGS/ASS 等不一定被浏览器暴露。
已经烧入像素的字幕无法通过“关闭字幕”删除；其他播放器能关闭的通常是软字幕，
并不是把画面里压进去的字抹掉。不要据此承诺自动去硬字幕。

可在观影前准备英文、中文、俄语 SRT，各自从**同一源时间轴**翻译，保留序号和时间。
本站没有云翻译/ASR 功能或付费 API。机翻需校对人物、语境、否定、专名及脏话，
不保证地道或版权许可。字幕来源网站/第三方软件的条款与本项目无关。

## 有偏差时

- 固定偏差：通常先核对剪辑/片头，使用本地偏移微调。
- 从中间开始却出现片头台词：核对是否绑定本地源，是否走了外部网页手动计时。
- 越播偏越多：核对帧率版本、倍速、源页心跳及实际暂停事件。
- 观众视频冻结但字幕继续：这是接收视频和控制时钟分离的限制；记录观众端
  活动路由/解码帧率/缓冲现象，不靠反复调字幕偏移掩盖网络问题。

当前不是逐帧绑定到 WebRTC RTP 的字幕协议，不能承诺所有网络下零误差。
