# 数据流与自部署隐私说明

这是项目的技术说明，不代替部署者适用的完整隐私政策。每个部署者须按实际运营
补充主体、联系渠道、处理目的/依据、保存期、权利请求和服务商说明。

| 数据 | 当前去向 |
| --- | --- |
| 本地原片 / M4A 文件 | 在源浏览器创建本地 object URL，不经 Worker 上传文件本体 |
| 实时画面与声音 | WebRTC 传给观看者；可能经 Cloudflare SFU/TURN，接收者可以录屏 |
| 房间、邀请、昵称、字幕及时钟状态 | Worker/SQLite Durable Objects，授权成员可访问相关房间数据 |
| 管理员设置的站名、标语、默认昵称等 | Directory Durable Object 单独记录，作为全站公开展示信息返回访问者 |
| 聊天、反应 | 房间内实时发送，不由应用长期写入聊天历史；接收者仍可截图/保存 |
| 登录 Cookie、标签页 ID、昵称/画质/字幕偏好 | 浏览器 Cookie、sessionStorage/localStorage 等 |
| 网络地址、路由及质量数据 | P2P 对端及云服务可观察所需元数据；质量摘要向房间主持人呈现 |
| 本地转换设置 / 缓存 / 错误日志 | 本机用户配置目录及输出旁文件，日志可能含本地路径 |

邀请制不是匿名制，也不是对 Cloudflare 的端到端保密保证。WebRTC 传输加密不等于
本项目实现独立的 E2EE 媒体层。P2P 候选/连接可能向对端暴露地址及网络信息；
隐藏真实地址需要额外设计和成本，当前没有强制全部中继的隐私模式。

房间期限为 1–168 小时；房间清理保留期与过期目录清理由代码定义（当前约过期/结束后
7 天），管理员可手动删除。目录清理不等于底层存储已瞬时抹除，云服务还有其自身日志/保留策略。
配置中默认关闭 Worker observability；部署者开启日志后应限制访问、设置合适保存期并脱敏。
前端没有加入第三方广告/跟踪 SDK；不能据此声称云服务本身不处理日志或元数据。

跨境使用前评估媒体及控制数据的服务区域、法律义务和同伴知情同意。
不要在公开 Bug 报告里贴邀请 URL、Cookie、真实姓名、字幕内容或无关媒体。
