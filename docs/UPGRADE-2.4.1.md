# 2.4.1：Host 站点设置

本包仅为本地交付，没有推送 GitHub、合并分支或部署 Cloudflare。
你现有的线上服务不会仅因下载/解压这个包而升级。

## 更新前

- 保留自己的 Worker 名称、域名/路由、Secrets、绑定和迁移记录。
  包内 wrangler.jsonc 仍是中性部署模板，不要盲目覆盖生产配置。
- 先确认 Cloudflare 自动部署触发范围。若任何分支都会部署正式站点，上传测试分支
  也可能影响线上；建议限定 main 后再更新仓库。
- 网站必须完整更新 public、src 和测试/锁文件，不能只上传表单 HTML。
  保留 test 目录；没有新服务、数据库或 Durable Object 迁移需要配置。

## 部署后怎么使用

1. 在自己的 `/api/config` 确认 version 为 `2.4.1`、release 为
   `2.4.1-host-settings-20261029`。
2. 刷新 `/host`，用现有管理员密码登录。
3. 在创建房间上方找到“站点设置”。未保存过的实例会自动展开。
4. 修改站名、标语、默认主持人昵称或房间默认标题；展开高级项可改首页文案等。
5. 点击“保存设置”：当前页面立即更新，其他访问者刷新后读取新文字，不需再次部署。

默认昵称适用于主持人下次进入房间；不会修改已在线参与者的名字。
新房间默认标题不会重命名已有房间。恢复默认仅清除这条设置，不删除房间或字幕。
读取失败时不能保存，防止把默认值覆盖掉原设置；刷新重试。

## 权限与范围

仅站点管理员可保存/恢复。房间主持人邀请不等于站点管理员。
设置都是公开文字，不要填写账号密码、API 密钥或私密联系信息。
该面板不修改 Worker、域名、管理员密码、云端凭据、编解码参数或媒体路由。

数据保存在既有 Directory Durable Object 的 siteSettings 记录，清浏览器缓存或更换
电脑不会丢失。读取和写入仍计入既有云服务额度，不代表新增用量完全不计费。

从 2.4.0 升级不改 token issuer，签名密钥相同的现有邀请/会话仍兼容。
从更早个性化旧版升级的邀请兼容性限制仍按 PUBLISHING.md 处理。
